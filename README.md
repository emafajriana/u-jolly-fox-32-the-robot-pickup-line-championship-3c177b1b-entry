An entry for the [Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun: one pickup line, in the voice of a robot trying to charm someone.

> My obstacle sensors detect nothing ahead — except you, and I have never once tried to avoid you.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` in the grader), then reads it back and verifies it byte for byte.

```bash
python3 main.py
```
